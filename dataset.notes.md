# Dataset Notes

## Format
The dataset is stored in JSONL format, with one instruction / input / output example per line.

## Purpose
The examples are synthetic and designed to test how a model handles entertainment-finance language.

## Domain focus
- studio financing
- pre-sales
- back-end points
- marketing recoupment
- distribution guarantees
- ancillary rights

## Intended use
- instruction tuning
- prompt testing
- response evaluation
- domain adaptation experiments
